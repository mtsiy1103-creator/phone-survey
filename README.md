# 폰측량 (PhoneSurvey)

휴대폰과 저렴한 외장 GNSS 수신기로 하는 참고용 현황측량 안드로이드 앱입니다.

## 기능
- 위치 소스: 휴대폰 내장 GPS / USB 외장 수신기(OTG) / 블루투스 외장 수신기(SPP)
- NTRIP 보정정보 수신 후 수신기로 전달 (국토지리정보원 VRS 등), 마운트포인트 목록 불러오기
- 측위 상태(단독/DGPS/Float/Fix), 위성 수, HDOP, 수평·수직 오차 표시
- 기계고 입력 → 지반고 = 표고 − 기계고 + 현장 보정값
- 평면좌표: 중부(EPSG:5186, 기본)·서부·동부·동해 원점, UTM-K
- 국가 지오이드 모델 파일(ISG 형식 또는 위도 경도 지오이드고 표) 적용
- N초 평균 측정, 점번호 자동 증가, 코드명(최근 코드 바로 선택)·메모
- 점 목록(수정·삭제), 도면 화면(확대·이동, 현재 위치)
- CSV(엑셀용 UTF-8) / DXF(R12, 코드별 레이어, 점번호·표고·코드 글자) 내보내기

## 구조
- `core/` 순수 Kotlin 로직: 좌표변환(Krüger 급수, PROJ와 1mm 이내 일치), NMEA 해석, 평균, 지오이드 보간, CSV/DXF, NTRIP 클라이언트. `./gradlew :core:test`로 어디서든 테스트됩니다.
- `app/` 안드로이드 앱(Jetpack Compose).

## 빌드
- GitHub에 올리면 `.github/workflows/build.yml`이 테스트 후 APK를 만들어 Actions 결과물(phone-survey-apk)로 올립니다.
- 직접 빌드: Android Studio로 폴더를 열거나 `./gradlew :app:assembleRelease` (Android SDK 필요).

## 현장 사용 순서
1. 설정 → 위치 소스 선택 (USB면 통신 속도, 블루투스면 페어링한 수신기)
2. 설정 → NTRIP 주소·포트·마운트포인트·아이디·비밀번호 입력
3. 측정 화면 → 연결 → RTK Fix 확인 → 점번호·코드 입력 → 측정 저장
4. 목록 화면 → CSV 또는 DXF로 내보내기

## 주의
- 참고용 도구입니다. 법정 측량 성과로 쓸 수 없습니다.
- 표고는 지오이드 모델 품질에 좌우됩니다. 기지점(수준점)에서 측정해 현장 보정값을 넣으면 좋습니다.
